# Contributing

Bahasa Indonesia and English are welcome. This project is at the planning stage.

## Ways to help

- Review architecture, recovery, privacy, storage portability, and offline behavior.
- Prototype Android networking with reproducible real-device measurements.
- Improve documentation, accessibility plans, and translations.
- Report bugs once runnable components exist.

## Workflow

1. Search existing issues and pull requests.
2. Discuss substantial protocol, dependency, or architecture changes in an issue.
3. Fork the repository and create a focused branch.
4. Make the smallest coherent change. Document behavior, limitations, and provenance.
5. Run checks relevant to the change and report actual commands/results. For documentation, check links and consistency. Never claim tests passed if they were not run.
6. Open a pull request describing the problem, solution, validation, and outstanding risks.

There is no application build or automated test suite yet. Add reproducible build instructions with the first runnable component.

## Dependencies and licensing

Do not copy code with missing or unclear permission. Record source URL, pinned commit/tag, license, modified files, transitive dependencies, and required notices before importing code. Keep credentials, personal media, tokens, and private logs out of commits.

Contributors retain copyright to their work and submit contributions under this repository's MIT license, except clearly identified third-party material under its original compatible terms. Submit only material you have the right to contribute.

## Review and decisions

The repository owner is the initial maintainer. Changes merge after maintainer review. Significant decisions should be recorded in a pull request or architecture decision document. No response-time commitment is promised.

Be respectful. Critique ideas and code; do not harass, discriminate, disclose private information, or attack people. Maintainers may close disruptive discussions and reject contributions that conflict with these expectations.
